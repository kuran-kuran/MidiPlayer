# MidiPlayer

Midiプレイヤーです

## 動作環境
Windows11Proで動作確認しています

## 操作方法
MidiPlayer.exeをダブルクリックすると起動します。  
midファイルやフォルダをウインドウにドロップするとプレイリストが作成されます。  
再生ボタンを押すと再生が開始します
